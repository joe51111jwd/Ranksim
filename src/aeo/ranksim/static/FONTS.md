# Fonts served by the Studio

- `inter.woff2`: Inter variable, Latin subset, weights 100 to 900. From `@fontsource-variable/inter@5.1.1` (`files/inter-latin-wght-normal.woff2`). SIL Open Font License 1.1, https://github.com/rsms/inter.
- `mono.woff2`: JetBrains Mono variable, Latin subset. From `@fontsource-variable/jetbrains-mono@5.1.1` (`files/jetbrains-mono-latin-wght-normal.woff2`). SIL Open Font License 1.1, https://github.com/JetBrains/JetBrainsMono.

Both are bundled so every device shows the same sans serif type, with no request to a font host.
