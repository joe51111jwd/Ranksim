# Fonts served by the Studio

- `sans.woff2`: Geist variable, Latin subset, weights 100 to 900. From `@fontsource-variable/geist@5.2.5` (`files/geist-latin-wght-normal.woff2`). SIL Open Font License 1.1, https://github.com/vercel/geist-font.
- `mono.woff2`: Geist Mono variable, Latin subset. From `@fontsource-variable/geist-mono@5.2.5` (`files/geist-mono-latin-wght-normal.woff2`). SIL Open Font License 1.1.

Both are bundled so every device shows the same sans serif type, with no request to a font host.
